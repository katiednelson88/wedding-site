# Ktizzle and Mattyrizz wedding site

Static site for 26–28 May 2028 at Blairmore Millhouse, Inverness.

Pages: index (The Lore), plan, guide, rsvp, advice. Shared styles.css and site.js.
Page sources live in `_src/` (rebuilt with build.py). Forms post to the Google Apps Script URL set in `site.js`.
